# SportsOS Documentation

This directory contains the architectural, operational, and engineering documentation for SportsOS.

## Documentation areas

### Architecture

System boundaries, component responsibilities, event design, database practices, and project structure.

- [`architecture/`](architecture/)

### Architecture Decision Records

Permanent records explaining significant technical decisions and their tradeoffs.

- [`adr/`](adr/)

### Engineering standards

Coding, API, UI, testing, contribution, and release standards.

- [`standards/`](standards/)

### Roadmap

Product direction, release planning, and versioning policy.

- [`roadmap/`](roadmap/)

### Sprints

Historical and active sprint documentation.

- [`sprints/`](sprints/)

### Requests for Comments

Design proposals for major features or architectural changes.

- [`rfc/`](rfc/)

## Documentation rule

A significant feature is not complete until its architecture, API behavior, domain events, permissions, migration impact, and operational requirements are documented.
